# Workout Tracker

Веб-приложение для управления тренировками, генерации планов и контроля прогресса.

Стек: Node.js, Express, SQLite, JWT, bcryptjs, Chart.js.

---

Функциональность

- Регистрация и авторизация пользователей (JWT)
- Создание, просмотр, обновление статуса и удаление тренировок
- Добавление упражнений к тренировке (название, подходы, повторения, вес)
- Генерация недельного плана тренировок через ИИ-помощника
- Статистика: диаграмма выполненных и запланированных тренировок
- Админ-панель: просмотр пользователей и их тренировок, удаление тренировок
- Ролевая модель: пользователь / администратор

Установка и запуск

git clone https://github.com/Shuhardin/workout-tracker.git
cd workout-tracker
npm install
node seedExercises.js
node server.js

Приложение доступно по адресу: http://localhost:3000

---

Роли

user - базовый функционал: тренировки, статистика, ИИ-помощник
admin - дополнительно: просмотр пользователей, их тренировок, удаление тренировок

Чтобы сделать пользователя администратором, измените поле role в таблице users:

UPDATE users SET role = 'admin' WHERE id = 1;

API

POST   /register                          - регистрация
POST   /login                             - авторизация
GET    /api/workouts                      - получить тренировки пользователя
POST   /api/workouts                      - создать тренировку
PUT    /api/workouts/:id                  - обновить статус тренировки
DELETE /api/workouts/:id                  - удалить тренировку
GET    /api/stats                         - статистика тренировок
POST   /api/ai-workout                    - генерация плана (ИИ)
GET    /api/admin/users                   - список пользователей (админ)
GET    /api/admin/workouts/:userId        - тренировки пользователя (админ)
DELETE /api/admin/workouts/:id            - удалить тренировку (админ)
